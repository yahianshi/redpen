Quick Setup Guide (1 Minute)

1

Create Google Cloud Project

Visit Google Cloud Console and create or select a project.

2

Enable Required Google APIs

In APIs & Services > Library, enable:

  • Google Drive API
  • Google Classroom API
3

Configure OAuth Consent & Credentials

Under APIs & Services > Credentials:

  1. Click Create Credentials > OAuth client ID.
  2. Select Web application.
  3. Under Authorized redirect URIs, paste the Redirect URI copied from the left box.
  4. Click Create, copy the generated Client ID, and paste it into the field on the left.
4

Start Grading in Google Classroom

Navigate to any Google Classroom assignment submission. You will see the ✏️ Grade with RedPen button in the right sidebar.

🦁 Brave Browser Compatibility Note

Brave blocks Chrome's proprietary profile synchronization used by standard extensions. This extension uses chrome.identity.launchWebAuthFlow, which works natively and securely in Brave without requiring Chrome profile sync!
